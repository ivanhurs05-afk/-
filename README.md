# Сайт-портфолио директолога

Статичный сайт (HTML/CSS/JS), сборка не нужна. Открыть `index.html` или залить папку на любой хостинг (GitHub Pages, Netlify, Cloudflare Pages).

- Фото: положите файл `assets/ivan.jpg` (портрет, пропорции 4:5). Пока его нет, показывается буква «И».
- Контакты и тексты: правятся прямо в `index.html`.
- Данные графиков: атрибуты `data-series` у блоков `.chart`.
