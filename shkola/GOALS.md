# Цели Яндекс Метрики (счётчик 103512796)

Создайте в Метрике: Настройка → Цели → Добавить цель → «JavaScript-событие». В поле «Идентификатор цели» впишите значение из таблицы.

| Идентификатор | Название цели | Когда срабатывает | Роль |
|---|---|---|---|
| lead_form | Заявка отправлена | форма успешно отправлена | главная конверсия (для Директа) |
| form_start | Начал заполнять форму | первый фокус в любом поле формы | промежуточная |
| click_phone | Клик по телефону | нажатие на номер | конверсия-звонок |
| click_cta | Клик по кнопке записи | кнопки «Бесплатное занятие», «Записаться», «Узнать стоимость» | вовлечённость |
| click_group_prices | Открыл цены на группу | кнопка «Цены на группу» | вовлечённость |
| faq_open | Открыл вопрос | раскрытие вопроса в FAQ | вовлечённость |
| scroll_50 | Прокрутка 50% | дошёл до середины страницы | вовлечённость |
| scroll_90 | Прокрутка 90% | дошёл почти до конца | вовлечённость |

События отправляются только после согласия посетителя на cookie.
