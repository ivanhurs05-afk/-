# Приём заявок на почту (лендинг zavod/)

Форма и квиз отправляют заявку функции в Яндекс Облаке, а она присылает письмо на вашу почту.
Данные проходят только через российские серверы (Яндекс Облако, Почта Mail.ru).
Пока `leadEndpoint` в `zavod/legal.js` пустой, форма открывает Telegram с готовым сообщением.

## Настройка (около 15 минут)
1. В почте (для ящика @inbox.ru): «Настройки → Пароли и безопасность → Пароли для внешних приложений», создайте пароль для «SMTP». Основной пароль не используйте.
2. Яндекс Облако → Cloud Functions → «Создать функцию», среда Node.js 18+, вставьте код из `yc-function-mail.js`, точка входа `yc-function-mail.handler` (если файл называется index.js: `index.handler`).
3. Переменные окружения функции: `SMTP_HOST=smtp.mail.ru`, `SMTP_PORT=465`, `SMTP_USER=ящик-отправитель`, `SMTP_PASS=пароль-для-внешних-приложений`, `MAIL_TO=куда присылать`, `ALLOWED_ORIGIN=https://ivanhurs05-afk.github.io`.
4. Сделайте функцию публичной, скопируйте ссылку вызова.
5. Впишите ссылку в `zavod/legal.js` → `leadEndpoint`.
6. Отправьте тестовую заявку с сайта и проверьте почту (и папку «Спам»).

`yc-function.js` — вариант с отправкой в Telegram-бота, если понадобится.
