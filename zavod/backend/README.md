# Приём заявок с лендинга (zavod/)

Пока `leadEndpoint` в `legal-config.js` пустой, форма открывает Telegram с готовым сообщением.
Чтобы заявки приходили сами и сохранялись на российских серверах:

1. В Яндекс Облаке создайте функцию (Cloud Functions, Node.js 18+), вставьте код из `yc-function.js`.
2. В переменных окружения задайте `TG_TOKEN`, `TG_CHAT_ID` и `ALLOWED_ORIGIN` (адрес сайта).
3. Сделайте функцию публичной и включите вызов по HTTPS, скопируйте ссылку.
4. Впишите ссылку в `legal-config.js` → `leadEndpoint`.
