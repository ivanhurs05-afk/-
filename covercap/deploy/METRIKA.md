# Яндекс Метрика: счётчик 114193683

## Как подключено
Счётчик подключается кодом сайта, а не вставкой скрипта на страницу. Номер хранится в `content.json` (админка → «Цены и контент» → «Номер счётчика Яндекс Метрики»). Метрика включается **только после того, как посетитель нажал «Разрешить» в баннере cookies**. До согласия она не загружается и ничего не считает. Из-за этого цифры в Метрике будут немного меньше реального трафика: отказавшиеся не видны.

Вебвизор выключен (`webvisor: false`): он записывает действия на странице, в том числе ввод в формы, а там имя и телефон. Если когда-нибудь понадобится включить, сначала нужно дополнить политику конфиденциальности. Поля формы уже помечены `ym-disable-keys`, чтобы их содержимое не попадало в записи.

В параметры целей имя, телефон и текст комментария не отправляются.

## Цели (создаются в интерфейсе Метрики)
Метрика → «Настройка» → «Цели» → «Добавить цель» → условие **«JavaScript-событие»** → в поле «Идентификатор цели» впишите значение из таблицы.

| Идентификатор | Название в Метрике | Когда срабатывает |
|---|---|---|
| `lead_success` | **Заявка отправлена** (основная, сделайте конверсией) | Сервер подтвердил сохранение заявки. Один раз на заявку |
| `quote_open` | Открыта форма расчёта | Открылась форма; в параметре `placement` — какая кнопка: header, hero, catalog, price, footer, mobile_bar, repeat, popup |
| `form_start` | Начал заполнять форму | Первый набранный символ в форме |
| `lead_error` | Ошибка отправки формы | Форма не отправилась (в параметре только код ошибки) |
| `phone_click` | Клик по телефону | Нажали на номер телефона |
| `telegram_click` | Клик по Telegram | Нажали на ссылку Telegram |
| `email_click` | Клик по почте | Нажали на email |
| `contact_click` | Любой клик по контактам | Телефон, Telegram, почта, Instagram |
| `variant_select` | Выбран размер или цвет | Выбор в каталоге, форме или на первом экране |
| `popup_shown` | Показан попап | Появилась форма через 45 секунд |
| `popup_dismiss` | Попап закрыт без заявки | Закрыли попап, не отправив форму |
| `catalog_view` | Просмотрен каталог | Блок «Ассортимент» виден на экране |
| `price_view` | Просмотрена цена | Блок «Цена» виден на экране |
| `faq_view` | Просмотрены вопросы | Блок «Вопросы» виден на экране |
| `scroll_50` | Прокрутка 50% | Дошли до середины страницы |
| `scroll_90` | Прокрутка 90% | Дошли почти до конца |
| `proposal_download` | Скачано КП | Если в админке указан PDF коммерческого предложения |

## Офлайн-конверсии (оплаты и качество заявок)
`qualified_lead` и `order_paid` отправляются файлом: админка → «Отчёт» → «Офлайн-конверсии для Метрики, CSV». В Метрике: «Настройка» → «Загрузка данных» → «Офлайн-конверсии». Для них заранее создайте цели с этими же идентификаторами. Повторная загрузка того же файла оплату не задваивает.

## Проверка
1. Откройте сайт, нажмите «Разрешить» в баннере cookies.
2. Нажмите на телефон, откройте форму, отправьте тестовую заявку.
3. В Метрике: «Отчёты» → «Стандартные отчёты» → «Содержание» → «Цели» (или «Настройка» → «Цели»): через 5–15 минут в целях появятся события.
