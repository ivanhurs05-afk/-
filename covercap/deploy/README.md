# Перенос COVERCAP на свой домен (Рег.ру)

Архив сайта собирается командой (подставьте свой домен):

```bash
python3 covercap/deploy/build.py --domain covercap.ru --out ./release
```

Команда печатает адрес админки, логин и пароль. Пароль показывается один раз; после первого входа его можно сменить в админке → «Пароль».

## 1. Купить домен и хостинг

- Домен — в Рег.ру, раздел «Домены».
- Хостинг — любой тариф виртуального хостинга с PHP 8 (базовых тарифов хватает: сайт весит меньше 1 МБ). При заказе хостинга укажите этот домен — Рег.ру сам пропишет для него свои DNS-серверы. Сайт начнёт открываться по домену через несколько часов (обычно до суток).
- Хостинг в России — это обязательное условие: по ч. 5 ст. 18 152-ФЗ заявки с именами и телефонами должны сохраняться на серверах в РФ.

## 2. Загрузить сайт

1. Откройте панель управления хостингом (ISPmanager) → «Менеджер файлов».
2. Перейдите в папку сайта: `www/<ваш домен>/`. Если там есть стандартный `index.html` от хостинга — удалите его.
3. Загрузите архив `covercap-<домен>.zip` и распакуйте его («Извлечь») прямо в эту папку. Внутри должны оказаться `index.html`, `admin/`, `api/`, `assets/` и т.д. — не вложенной папкой.
4. Включите показ скрытых файлов и убедитесь, что есть `.htaccess` в корне, а также в папках `data/` и `private/`.

## 3. Настроить PHP

ISPmanager → «Сайты» → ваш домен → изменить → версия PHP 8.x (режим CGI или FastCGI). Расширения `pdo_sqlite` и `mbstring` на Рег.ру обычно включены.

## 4. Включить HTTPS

1. Выпустите бесплатный SSL-сертификат (Let's Encrypt): в личном кабинете Рег.ру или в ISPmanager → «SSL-сертификаты».
2. Когда сайт откроется по `https://`, в файле `.htaccess` (корень сайта) уберите `#` в начале четырёх строк под словами «HTTPS и домен без www» — тогда все адреса будут вести на `https://<домен>`.

## 5. Проверить

1. Откройте `https://<домен>/admin/`, войдите и нажмите «Проверка сервера» — все строки должны быть зелёными.
2. Проверьте, что закрытые файлы не открываются: `https://<домен>/private/config.php` и `https://<домен>/data/leads.sqlite` должны отдавать ошибку 403.
3. Отправьте с сайта тестовую заявку: она должна появиться в админке и прийти на почту из `content.json` (ivan.khurs@inbox.ru). Письма с хостинга иногда попадают в «Спам» — отметьте первое как «Не спам».
4. Смените пароль админки («Пароль»).

## 6. После запуска

- Подать уведомление об обработке персональных данных в Роскомнадзор (pd.rkn.gov.ru), если ещё не подано.
- Добавить сайт в Яндекс Вебмастер и при желании подключить Метрику (номер счётчика — в админке, «Цены и контент»).
- Копию на GitHub Pages перевести на новый домен (редирект), чтобы не было двух одинаковых сайтов.

## Обновление сайта

Пересоберите архив и загрузите поверх только изменённые файлы. **Не перезаписывайте** `data/` (там заявки и сменённый пароль), `content.json` (цены и реквизиты, которые правятся в админке) и `private/config.php`.
