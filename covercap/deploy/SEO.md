# SEO: чтобы сайт появился в поиске

Что уже сделано на самом сайте: заголовок и описание с поисковыми словами, один H1, расширенные вопросы и ответы, микроразметка (организация, сайт, товар без цены, вопросы), карта сайта `sitemap.xml` с датами, `robots.txt`, canonical, превью для соцсетей 1200×630, favicon (ico, svg, apple-touch), быстрая загрузка (Lighthouse SEO 100).

Что **нельзя сделать из кода**, это нужно сделать владельцу сайта.

## 1. Яндекс Вебмастер (главное для России)
1. webmaster.yandex.ru → «Добавить сайт» → `https://coffeface.ru`.
2. Подтверждение прав: способ «HTML-файл». Яндекс даст файл вида `yandex_xxxxxxxx.html`. Загрузите его в корень сайта (`www/coffeface.ru/`) через менеджер файлов и нажмите «Проверить».
3. «Индексирование» → «Файлы Sitemap» → добавьте `https://coffeface.ru/sitemap.xml`.
4. «Индексирование» → «Переобход страниц»: отправьте `https://coffeface.ru/` и страницы документов.
5. «Региональность» → укажите регион: Новосибирск.
6. Заполните «Информацию о сайте» (название COVERCAP, логотип, контакты).

## 2. Яндекс Метрика
1. metrika.yandex.ru → «Добавить счётчик» → адрес сайта.
2. Номер счётчика впишите в админке: «Цены и контент» → поле «Номер счётчика Яндекс Метрики». На сайте появится баннер о cookies; Метрика включается только после согласия посетителя.
3. Связать счётчик с Вебмастером (в настройках счётчика).

## 3. Google Search Console
search.google.com/search-console → «Добавить ресурс» → «Префикс URL» → `https://coffeface.ru/`. Подтверждение через HTML-файл (так же, как у Яндекса). Затем «Файлы Sitemap» → `sitemap.xml`.

## 4. Переадресация www → без www
ispmanager → «Сайты» → coffeface.ru → «Изменить» → «Редирект домена» → выберите перенаправление с `www` на основной домен. Иначе поисковик может считать две версии сайта дублями.

## 5. Где ещё указать сайт (ссылки с других мест повышают доверие)
- Яндекс Бизнес (Справочник) и 2ГИС, если есть адрес или зона обслуживания в Новосибирске.
- Описание профиля в Instagram и Telegram: ссылка на `https://coffeface.ru`.
- Профили на Авито и в каталогах поставщиков упаковки.

## Сроки и ожидания
- Новый сайт индексируется от нескольких дней до 2–4 недель; в Вебмастере можно ускорить через «Переобход страниц».
- На общие запросы вроде «крышки для стаканов» конкурируют маркетплейсы и крупные поставщики. Быстрее всего сайт будет находиться по узким запросам: «необычные крышки для кофе», «крышки для стаканов KISS», «крышки с носом и губами», а также по названию.
- Чтобы получать заявки сразу, не дожидаясь SEO, можно запустить Яндекс Директ на этот же сайт.
